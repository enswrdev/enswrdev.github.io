YT NexusPatch

A single-file userscript that gives YouTube and YouTube Music a cleaner, unified experience: Premium-inspired custom branding, lightweight cosmetic ad filtering and a tidier interface — no manual configuration required.

  • Custom branding across both platforms, with light and dark theme support
  • CSS-based cosmetic filtering and dynamic DOM cleanup of promotional elements
  • MutationObserver keeps changes applied through YouTube's single-page navigation
  • Automatic updates through the userscript manager's update source

Siren Flash App

A customizable police / EMS siren and flash controller for roleplay, simulation setups and emergency-signaling demos. Three sound modes, keyboard-driven sirens, alternating flash frames and live theme switching.

  • ARMAS, CSR and ZER modes with siren, horn and extended siren controls
  • Left / right flash system with a fullscreen icon overlay
  • First-run setup saves theme, language and media folder to a config file
  • Ships as a ready-to-run Windows build; source runs on Python 3.10–3.12

03 python · computer vision

Insta Ping Pong Bot

A real-time computer-vision bot for the Instagram DM ping-pong minigame, mirrored on Windows through Scrcpy. HSV colour tracking and trajectory prediction drive the paddle, with a local virtual wall compensating for latency and dropped frames.

  • Red-ball HSV mask with trajectory and wall-reflection prediction
  • Hybrid local wall sweeps ±30 px at ~1 ms to widen paddle coverage
  • Win32 mouse automation drags the paddle without manual clicks
  • Live OpenCV HUD for centroids, impact markers and shield bounds
